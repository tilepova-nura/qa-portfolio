## 🌐 Учебный проект №2: анализ сетевого трафика (Wireshark)

В рамках практики я провела анализ сетевого трафика с помощью снифера **Wireshark**:

- 🔐 Анализ TLS-рукопожатия (Client Hello, SNI)
- 🔓 Расшифровка HTTPS через SSLKEYLOGFILE

Все задания оформлены в отдельные папки с описаниями и скриншотами.
