## 🧪 Учебный проект: тестирование SauceDemo (Swag Labs)

В рамках самостоятельной практики я провела полное тестирование интернет-магазина **[SauceDemo (Swag Labs)](https://www.saucedemo.com/)** — это учебный сайт, созданный специально для практики тестировщиков. 

Проект включал тестирование всех ключевых сценариев:
- 🔐 Авторизация (5 типов пользователей)
- 🛍️ Каталог товаров и сортировка
- 🛒 Корзина и оформление заказа
- 📄 Генерация PDF-чека
- 📱 Мобильная адаптивность
- 🔒 Валидация полей ввода (граничные значения)
- 🐞 Работа с 5 разными типами пользователей (standard, problem, performance_glitch, error, visual)

Все артефакты оформлены в **Jira** и экспортированы в этот репозиторий.
