# Чек-листы

В этой папке собраны все чек-листы, созданные в ходе тестирования **SauceDemo (Swag Labs)**.

Чек-листы охватывают:
- Валидацию полей ввода (граничные значения)
- Авторизацию и UI
- Главную страницу (каталог товаров)
- Страницу товара
- Фильтры (сортировку)
- Корзину
- Бургер-меню
- Мобильную адаптивность
- Оформление заказа (Шаги 1, 2 и завершение)

Каждый чек-лист содержит проверки, их статус и ссылки на связанные баги или улучшения.

**Всего чек-листов:** 11
