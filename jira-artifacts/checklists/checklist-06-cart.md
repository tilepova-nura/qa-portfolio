**Найденные баги:**
- [BUG-10](../bugs/BUG-10.md) — Кнопка "Back" на странице товара возвращает на главную, а не в корзину
- [BUG-31](../bugs/BUG-31.md) — Долгая загрузка всех страниц и действий для performance_glitch_user
- [BUG-44](../bugs/BUG-44.md) — Кнопка "Checkout" в корзине съехала для visual_user

**Найденные улучшения:**
- [IMP-11](../improvements/IMP-11.md) — Добавить изображения товаров в корзине
- [IMP-12](../improvements/IMP-12.md) — Добавить чек-боксы для выбора товаров в корзине
- [IMP-13](../improvements/IMP-13.md) — Добавить сообщение о пустой корзине
- [IMP-14](../improvements/IMP-14.md) — Добавить выбор количества товара в корзине

**Связанные тест-кейсы:** [TC-11](../test-cases/TC-11.md), [TC-12](../test-cases/TC-12.md), [TC-17](../test-cases/TC-17.md)

**Примечания:**
- Основная функциональность корзины работает (добавление, удаление, отображение названий и цен).
- Отсутствуют ключевые элементы UX: изображения, выбор количества, чек-боксы, сообщение о пустой корзине.
- Навигация из карточки товара работает некорректно при возврате в корзину.
- Для performance_glitch_user переход на главную происходит с критической задержкой.
- Для visual_user кнопка "Checkout" в корзине имеет некорректное позиционирование.
