**Статус:** ❌ Провален

**Найденные баги:**
- **BUG-13** — Кнопка "Cancel" возвращает на главную, а не на Шаг 1
- **BUG-14** — Кнопка "Back" из карточки товара (из Overview) возвращает на главную
- **BUG-15** — Мелкий шрифт итоговой суммы
- **BUG-16** — Отсутствуют изображения товаров в Overview
- **BUG-29** — Прямой доступ к странице Checkout: Overview без заполнения данных возможен для problem_user
- **BUG-36** — Прямой доступ к странице Checkout: Overview без заполнения данных возможен для error_user
- **BUG-45** — Кнопка "Finish" не работает для error_user

**Найденные улучшения:**
- **IMP-21** — Добавить анимацию для всех кнопок
- **IMP-22** — Увеличить шрифт итоговой суммы
- **IMP-23** — Добавить изображения товаров в Overview

**Примечания:**
- Страница содержит множество критических проблем с навигацией и доступом.
- Для problem_user и error_user возможен прямой доступ к странице без заполнения Шага 1.
- Кнопки "Cancel" и "Back" работают некорректно (ведут на главную страницу).
- Для error_user кнопка "Finish" не работает полностью, что блокирует завершение заказа.
- Итоговая сумма плохо читается из-за мелкого шрифта.
- Отсутствуют изображения товаров в списке.
- Рекомендуется исправить навигацию, добавить анимации для кнопок и восстановить работу кнопки "Finish" для error_user.
