# Баг-репорты

В этой папке собраны все баги (дефекты), найденные в ходе тестирования **SauceDemo (Swag Labs)**.

Каждый баг-репорт содержит:
- Уникальный идентификатор (BUG-XX)
- Шаги для воспроизведения
- Фактический результат
- Ожидаемый результат
- Серьёзность (Critical / Major / Minor / Trivial)
- Приоритет (High / Medium / Low)
- Окружение (браузер, ОС)
- Ссылки на видео или скриншоты (при наличии)
- Связанные тест-кейсы и чек-листы

Баги разделены по категориям:
- **Производительность** (долгая загрузка, задержки)
- **Визуальные нарушения** (некорректное отображение, съехавшие элементы)
- **Функциональные ошибки** (неработающие кнопки, фильтры, навигация)
- **Валидация** (пробелы, длина, спецсимволы)
- **Навигация** (неправильные переходы)
- **Работа с PDF** (нечитаемые данные, отсутствие информации)

**Всего багов:** 45
