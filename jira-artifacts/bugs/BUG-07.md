# BUG-07: Поле "Username" принимает только пробелы как валидный ввод

**Шаги для воспроизведения:**
1. Ввести в поле "Username" пробелы (" ")
2. Нажать "Login"

**Фактический результат:**
Поле принимает пробелы как валидный ввод.

**Ожидаемый результат:**
Должна появляться ошибка: "Username is required".

**Серьёзность:** Minor
**Приоритет:** Low
**Окружение:** Google Chrome v120, Windows 11
