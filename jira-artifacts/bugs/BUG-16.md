# BUG-16: На странице Checkout: Overview не отображаются изображения товаров

**Шаги для воспроизведения:**
1. Перейти на страницу Checkout: Overview
2. Посмотреть на список товаров

**Фактический результат:**
Изображения товаров отсутствуют (как и в корзине). Только название, описание и цена.

**Ожидаемый результат:**
Рядом с каждым товаром должно отображаться его изображение (миниатюра), чтобы пользователь мог визуально идентифицировать товар.

**Серьёзность:** Minor
**Приоритет:** Medium
**Окружение:** Все браузеры
