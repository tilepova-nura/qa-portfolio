# BUG-44: Кнопка "Checkout" в корзине съехала

**Шаги для воспроизведения:**
1. Авторизоваться под пользователем visual_user / secret_sauce
2. Добавить любой товар в корзину
3. Перейти в корзину (Cart)
4. Обратить внимание на кнопку "Checkout"

**Фактический результат:**
Кнопка "Checkout" имеет абсолютное позиционирование и находится в верхней части страницы вместо нижней. Некорректные стили:

```css
.btn_visual_failure {
    position: absolute;
    top: 0;
    right: 0;
}
```

**Ожидаемый результат:**
Кнопка "Checkout" должна находиться в нижней части страницы (под списком товаров), как у стандартного пользователя.

**Серьёзность:** Minor
**Приоритет:** Medium
**Окружение:** Все браузеры, пользователь visual_user
