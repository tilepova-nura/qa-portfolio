# BUG-32: Отсутствие визуальных индикаторов загрузки для performance_glitch_user

**Шаги для воспроизведения:**
1. Авторизоваться под пользователем performance_glitch_user / secret_sauce
2. Выполнить любое действие, вызывающее долгую загрузку (переход на страницу товара, выбор фильтра, переход на "About")

**Фактический результат:**
Во время долгой загрузки нет никаких визуальных индикаторов (спиннеров, прогресс-баров, сообщений о загрузке). Пользователь не понимает, происходит ли что-то или система зависла.

**Ожидаемый результат:**
При долгих операциях должен отображаться индикатор загрузки, чтобы пользователь понимал, что процесс выполняется.

**Серьёзность:** Minor
**Приоритет:** Medium
**Окружение:** Все браузеры, пользователь performance_glitch_user
