# BUG-24: Нельзя добавить больше 2 товаров в корзину для problem_user

**Шаги для воспроизведения:**
1. Авторизоваться под пользователем problem_user / secret_sauce
2. Попробовать добавить товары в корзину (3-й, 4-й, 5-й, 6-й товары)

**Фактический результат:**
В корзину можно добавить только первые 2 товара. На остальных кнопка "Add to cart" не реагирует или после нажатия ничего не происходит.

**Ожидаемый результат:**
Должна быть возможность добавить все 6 товаров в корзину.

**Серьёзность:** Critical
**Приоритет:** High
**Окружение:** Все браузеры, пользователь problem_user
