# BUG-04: Визуальные нарушения для visual_user

**Шаги для воспроизведения:**
1. Войти под `visual_user` / `secret_sauce`
2. Просмотреть страницу товаров

**Фактический результат:**
1. Карточки товаров накладываются друг на друга, нарушены отступы.
2. Вместо изображений товаров отображается фото собачки.
3. Иконка корзины съехала с положенного места.

**Ожидаемый результат:**
1. Карточки товаров выровнены ровно, отступы соответствуют макету.
2. Все изображения товаров отображаются корректно.
3. Иконка корзины находится на своём месте.

**Серьёзность:** Minor
**Приоритет:** Medium
**Окружение:** Google Chrome v120, Windows 11
