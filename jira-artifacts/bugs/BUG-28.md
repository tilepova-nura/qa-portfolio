# BUG-28: Невозможно заполнить данные на странице Checkout для problem_user

**Шаги для воспроизведения:**
1. Авторизоваться под пользователем problem_user / secret_sauce
2. Перейти на страницу Checkout: Your Information (checkout-step-one.html)
3. Попробовать заполнить поля (First Name, Last Name, Zip/Postal Code)

**Фактический результат:**
Поля не заполняются. При вводе данных они не отображаются, либо при заполнении одного поля очищается другое.

**Ожидаемый результат:**
Все поля должны корректно заполняться и сохранять введённые данные.

**Серьёзность:** Critical
**Приоритет:** High
**Окружение:** Все браузеры, пользователь problem_user
