# BUG-37: PDF-заказ для error_user не содержит данных

**Шаги для воспроизведения:**
1. Авторизоваться под пользователем error_user / secret_sauce
2. Оформить заказ
3. На странице подтверждения нажать "Generate PDF order"
4. Открыть сгенерированный PDF-файл

**Фактический результат:**
В PDF-файле отсутствует информация о заказе: нет имени пользователя, адреса доставки, номера заказа. Есть только сумма.

**Ожидаемый результат:**
PDF-документ должен содержать всю информацию о заказе: номер заказа, имя пользователя, адрес доставки, список товаров с количеством, итоговую сумму.

**Серьёзность:** Major
**Приоритет:** High
**Окружение:** Все браузеры, пользователь error_user
