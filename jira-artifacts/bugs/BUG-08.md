# BUG-08: Поле "Password" принимает пробелы в начале и конце

**Шаги для воспроизведения:**
1. В поле "Password" ввести ` secret_sauce ` (с пробелами)
2. Нажать "Login"

**Фактический результат:**
Пробелы не обрезаются. Вход не выполняется.

**Ожидаемый результат:**
Пробелы должны автоматически обрезаться. ИЛИ ошибка "Пароль не должен содержать пробелы".

**Серьёзность:** Minor
**Приоритет:** Medium
**Окружение:** Google Chrome v120, Windows 11
