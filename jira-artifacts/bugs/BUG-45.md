# BUG-45: Кнопка "Finish" на странице Checkout: Overview не работает для error_user

**Шаги для воспроизведения:**
1. Авторизоваться под пользователем error_user / secret_sauce
2. Добавить любой товар в корзину
3. Перейти на страницу Checkout: Step One (заполнить поля — если получится, или использовать прямой доступ к Шагу 2)
4. Перейти на страницу Checkout: Overview
5. Нажать кнопку "Finish"

**Фактический результат:**
Кнопка "Finish" не реагирует на нажатие. Заказ не завершается. Переход на страницу подтверждения (checkout-complete.html) не происходит. Дойти до PDF-заказа невозможно.

**Ожидаемый результат:**
При нажатии "Finish" заказ должен успешно завершаться, должен происходить переход на страницу подтверждения (checkout-complete.html), после чего должна быть доступна кнопка "Generate PDF order".

**Серьёзность:** Critical
**Приоритет:** High
**Окружение:** Все браузеры, пользователь error_user
