# BUG-30: В PDF-заказе для problem_user некорректно отображается итоговая сумма

**Шаги для воспроизведения:**
1. Авторизоваться под пользователем problem_user / secret_sauce
2. Оформить заказ
3. На странице подтверждения нажать "Generate PDF order"
4. Открыть PDF-файл

**Фактический результат:**
Итоговая сумма в PDF-файле отображается некорректно (задваивается или неправильно рассчитана).

**Ожидаемый результат:**
Итоговая сумма должна отображаться корректно.

**Приоритет:** High
