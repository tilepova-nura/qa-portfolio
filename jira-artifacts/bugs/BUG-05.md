# BUG-05: Сообщение об ошибке не исчезает при повторной попытке входа

**Шаги для воспроизведения:**
1. Ввести неверный пароль → появляется ошибка
2. Исправить пароль на верный и нажать "Login"

**Фактический результат:**
Сообщение об ошибке остаётся на экране даже после исправления данных.

**Ожидаемый результат:**
Сообщение об ошибке должно автоматически исчезать при повторной попытке входа.

**Серьёзность:** Minor
**Приоритет:** Medium
**Окружение:** Google Chrome v120, Windows 11
