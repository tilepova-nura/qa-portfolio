# BUG-41: Кнопка "Add to cart" съехала на последнем товаре

**Шаги для воспроизведения:**
1. Авторизоваться под пользователем visual_user / secret_sauce
2. На главной странице прокрутить список до последнего товара
3. Обратить внимание на кнопку "Add to cart"

**Фактический результат:**
Кнопка "Add to cart" на последнем товаре съехала вправо за пределы карточки товара. Некорректные стили:

```css
.btn_inventory_misaligned {
    position: absolute;
    right: -20px;
}
```

**Ожидаемый результат:**
Кнопка "Add to cart" должна находиться внутри карточки товара на своём штатном месте, без смещений.

**Серьёзность:** Minor
**Приоритет:** Medium
**Окружение:** Все браузеры, пользователь visual_user
