# BUG-27: Состояние кнопок не обновляется после сброса корзины для problem_user

**Шаги для воспроизведения:**
1. Авторизоваться под пользователем problem_user / secret_sauce
2. Добавить товары в корзину
3. Открыть бургер-меню и нажать "Reset App State"
4. Посмотреть на состояние кнопок на главной странице

**Фактический результат:**
Иконка корзины показывает 0, но на товарах всё ещё отображается "Remove" вместо "Add to cart".

**Ожидаемый результат:**
После сброса состояния все кнопки должны вернуться в исходное состояние ("Add to cart").

**Серьёзность:** Minor
**Приоритет:** Medium
**Окружение:** Все браузеры, пользователь problem_user
