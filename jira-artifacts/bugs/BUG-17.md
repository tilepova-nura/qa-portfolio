# BUG-17: В PDF-заказе отсутствует важная информация и отображаются нечитаемые данные

**Шаги для воспроизведения:**
1. Оформить заказ на сайте SauceDemo
2. На странице подтверждения (checkout-complete.html) нажать кнопку "Generate PDF order"
3. Открыть сгенерированный PDF-файл

**Фактический результат:**
PDF-файл содержит следующие проблемы:
1. В разделе "SHIP TO" отображаются нечитаемые данные вместо имени и адреса пользователя.
2. Отсутствует номер заказа.
3. Отсутствует информация о количестве товаров.
4. Нет детализации по каждому товару (только общая цена).
5. Отсутствует имя пользователя, оформившего заказ.

**Ожидаемый результат:**
PDF-документ должен содержать:
- Номер заказа.
- Имя и фамилию пользователя.
- Полный адрес доставки.
- Список всех заказанных товаров с указанием количества и цены за единицу.
- Итоговую сумму с детализацией (товары, налог, общая стоимость).
- Дату и время оформления заказа.

**Серьёзность:** Critical
**Приоритет:** High
**Окружение:** Все браузеры
