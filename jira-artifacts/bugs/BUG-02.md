# BUG-02: Некорректное отображение изображений для problem_user

**Шаги для воспроизведения:**
1. Войти под `problem_user` / `secret_sauce`
2. На странице товаров проверить изображения

**Фактический результат:**
Изображения некоторых товаров отсутствуют, вместо них отображается фото собачки. Текст описания товаров также отображается некорректно.

**Ожидаемый результат:**
Все изображения загружаются корректно. Текст описания отображается полностью и без искажений.

**Серьёзность:** Minor
**Приоритет:** Medium
**Окружение:** Google Chrome v120, Windows 11
