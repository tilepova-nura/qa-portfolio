# BUG-36: Для error_user возможен прямой доступ к странице Checkout: Overview без заполнения данных

**Шаги для воспроизведения:**
1. Авторизоваться под пользователем error_user / secret_sauce
2. В адресной строке ввести https://www.saucedemo.com/checkout-step-two.html

**Фактический результат:**
Страница открывается без заполнения данных на Шаге 1. Возможно завершение заказа без ввода имени, фамилии и почтового индекса.

**Ожидаемый результат:**
Прямой доступ к Шагу 2 должен быть запрещён, если не заполнены данные на Шаге 1.

**Серьёзность:** Critical
**Приоритет:** High
**Окружение:** Все браузеры, пользователь error_user
