# BUG-23: Некорректное отображение изображений для problem_user (собачки вместо товаров)

**Шаги для воспроизведения:**
1. Авторизоваться под пользователем problem_user / secret_sauce
2. На главной странице посмотреть на изображения товаров

**Фактический результат:**
Вместо изображений товаров отображаются изображения собачек.

**Ожидаемый результат:**
Должны отображаться корректные изображения товаров.

**Серьёзность:** Minor
**Приоритет:** Medium
**Окружение:** Все браузеры, пользователь problem_user
