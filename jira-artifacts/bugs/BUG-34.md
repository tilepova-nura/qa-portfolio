# BUG-34: Товары не удаляются из корзины для error_user

**Шаги для воспроизведения:**
1. Авторизоваться под пользователем error_user / secret_sauce
2. Добавить любой товар в корзину (кнопка "Add to cart")
3. Нажать кнопку "Remove" на том же товаре

**Фактический результат:**
Кнопка "Remove" не срабатывает. Товар остаётся в корзине. Счётчик корзины не обновляется.

**Ожидаемый результат:**
При нажатии "Remove" товар должен удаляться из корзины, счётчик должен обновляться.

**Серьёзность:** Major
**Приоритет:** High
**Окружение:** Все браузеры, пользователь error_user
