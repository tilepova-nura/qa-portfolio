# BUG-39: Некорректное позиционирование корзины для visual_user

**Шаги для воспроизведения:**
1. Авторизоваться под пользователем visual_user / secret_sauce
2. На главной странице обратить внимание на иконку корзины в правом верхнем углу

**Фактический результат:**
Иконка корзины имеет абсолютное позиционирование со стилями:

```css
.primary_header .shopping_cart_container.visual_failure {
    width: 40px;
    height: 40px;
    position: absolute;
    top: 40px;
    right: 205px;
}
```
Иконка находится не на своём месте, съехала вправо и вниз.

**Ожидаемый результат:**
Иконка корзины должна быть на своём месте в правом верхнем углу, без абсолютного позиционирования.

**Серьёзность:** Minor
**Приоритет:** Medium
**Окружение:** Все браузеры, пользователь visual_user
