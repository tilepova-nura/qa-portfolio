# BUG-06: Поле "Username" принимает пробелы в начале и конце

**Шаги для воспроизведения:**
1. Открыть Swag Labs
2. В поле "Username" ввести ` standard_user ` (с пробелами)
3. Нажать "Login"

**Фактический результат:**
Пробелы не обрезаются. Вход не выполняется.

**Ожидаемый результат:**
Пробелы должны автоматически обрезаться. ИЛИ ошибка "Логин не должен содержать пробелы".

**Серьёзность:** Minor
**Приоритет:** Medium
**Окружение:** Google Chrome v120, Windows 11
