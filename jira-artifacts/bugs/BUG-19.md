# BUG-19: Футер не растягивается на всю ширину экрана при ширине 465–900px

**Шаги для воспроизведения:**
1. Открыть сайт Swag Labs
2. Авторизоваться под любым пользователем
3. В DevTools (F12) выставить ширину экрана от 465px до 900px (планшетный режим)
4. Прокрутить страницу вниз к футеру

**Фактический результат:**
Футер занимает не всю ширину экрана, а только часть (inline box). Нарушается вёрстка, футер выглядит "оборванным".

**Проблемный код:**
```css
.footer {
    background-color: #132322;
    min-height: 140px;
    margin-top: auto;
    position: relative;
}
