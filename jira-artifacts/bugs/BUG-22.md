# BUG-22: Некорректное название товара "Test.allTheThings() T-Shirt (Red)"

**Шаги для воспроизведения:**
1. Авторизоваться под пользователем problem_user
2. На главной странице найти товар "Test.allTheThings() T-Shirt (Red)"

**Фактический результат:**
Название товара содержит лишний текст "Test.allTheThings()", который похож на вызов функции.

**Ожидаемый результат:**
Название должно быть чистым, без лишнего кода: "T-Shirt (Red)" или "Sauce Labs T-Shirt (Red)".

**Серьёзность:** Trivial
**Приоритет:** Low
**Окружение:** Все браузеры, пользователь problem_user
