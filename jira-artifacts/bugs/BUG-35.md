# BUG-35: Некорректное заполнение полей на странице Checkout для error_user

**Шаги для воспроизведения:**
1. Авторизоваться под пользователем error_user / secret_sauce
2. Перейти на страницу Checkout: Your Information (checkout-step-one.html)
3. Попробовать заполнить поле "Last Name"

**Фактический результат:**
При попытке заполнить поле "Last Name" введённые данные сразу удаляются. Поле не принимает текст.

**Ожидаемый результат:**
Поле должно принимать и сохранять введённый текст.

**Серьёзность:** Critical
**Приоритет:** High
**Окружение:** Все браузеры, пользователь error_user
