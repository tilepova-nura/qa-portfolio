# BUG-09: Поле "Password" принимает только пробелы как валидный ввод

**Шаги для воспроизведения:**
1. Ввести в поле "Password" пробелы (" ")
2. Нажать "Login"

**Фактический результат:**
Поле принимает пробелы как валидный ввод.

**Ожидаемый результат:**
Должна появляться ошибка: "Password is required".

**Серьёзность:** Minor
**Приоритет:** Low
**Окружение:** Google Chrome v120, Windows 11
