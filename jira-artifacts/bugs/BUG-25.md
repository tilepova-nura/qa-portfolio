# BUG-25: Товары не удаляются из корзины для problem_user

**Шаги для воспроизведения:**
1. Авторизоваться под пользователем problem_user / secret_sauce
2. Добавить товары в корзину
3. Попробовать удалить добавленные товары (нажать "Remove")

**Фактический результат:**
Товары не удаляются из корзины. Кнопка "Remove" не реагирует или после обновления страницы товары снова появляются.

**Ожидаемый результат:**
При нажатии "Remove" товары должны удаляться из корзины.

**Серьёзность:** Major
**Приоритет:** High
**Окружение:** Все браузеры, пользователь problem_user
