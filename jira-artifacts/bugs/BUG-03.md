# BUG-03: Кнопки "Add to cart/Remove" не работают для error_user

**Шаги для воспроизведения:**
1. Войти под `error_user` / `secret_sauce`
2. Нажать кнопку "Add to cart" на любом товаре

**Фактический результат:**
Кнопка не реагирует, товар не добавляется в корзину.

**Ожидаемый результат:**
Товар добавляется в корзину, кнопка меняется на "Remove".

**Серьёзность:** Critical
**Приоритет:** High
**Окружение:** Google Chrome v120, Windows 11
