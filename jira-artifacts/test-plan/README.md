# Тест-план: тестирование SauceDemo (Swag Labs)

**Дата создания:** 17.08.2026
**Тестировщик:** Нура Тилепова
**Объект тестирования:** [https://www.saucedemo.com/](https://www.saucedemo.com/)
**Тип проекта:** Учебный интернет-магазин

---

## 1. Введение

Данный тест-план описывает подход к тестированию сайта SauceDemo (Swag Labs) — учебного интернет-магазина, созданного специально для практики тестировщиков. Документ определяет объём, стратегию, ресурсы и критерии завершения тестирования.

---

## 2. Объект тестирования

**SauceDemo (Swag Labs)** — учебный интернет-магазин, имитирующий полноценный e-commerce сайт с каталогом товаров, корзиной и оформлением заказа.

**Ключевые особенности:**
- 6 типов пользователей с разным поведением (standard, locked_out, problem, performance_glitch, error, visual).
- Полный цикл покупки: выбор товара → корзина → оформление → подтверждение → PDF-чек.
- Фильтры и сортировка товаров.
- Мобильная и планшетная адаптивность.

---

## 3. Цель тестирования

1. Проверить корректность работы основного функционала сайта.
2. Выявить дефекты и оценить их серьёзность.
3. Проверить работу сайта под всеми типами пользователей.
4. Оценить удобство использования (UX).
5. Проверить валидацию полей ввода (граничные значения).
6. Проверить адаптивность на мобильных и планшетных устройствах.

---

## 4. Объём тестирования

### ✅ Включено в тестирование

| Раздел | Что проверяется |
|--------|-----------------|
| **Авторизация** | Вход под 5 типами пользователей, обработка ошибок |
| **Главная страница** | Отображение 6 товаров, кнопки "Add to cart", футер |
| **Страница товара** | Открытие карточки, кнопки добавления/удаления |
| **Фильтры** | Сортировка по имени (A→Z, Z→A) и по цене (low→high, high→low) |
| **Корзина** | Добавление, удаление, отображение товаров |
| **Бургер-меню** | Открытие/закрытие, переходы по пунктам |
| **Оформление заказа** | Шаг 1 (Your Information), Шаг 2 (Overview), Завершение |
| **PDF-заказ** | Генерация документа, содержимое, читаемость |
| **Валидация полей** | Граничные значения, пробелы, длина, спецсимволы, SQL-инъекции, XSS |
| **Мобильная адаптивность** | Отображение на 375px–1024px |

### ❌ Не включено в тестирование

- Нагрузочное тестирование.
- Тестирование безопасности (проверка уязвимостей).
- Тестирование производительности на реальных данных.
- Автоматизация тестирования (в планах).
- Тестирование на реальных мобильных устройствах (только эмуляция в DevTools).

## 5. Стратегия тестирования

### Типы тестирования

| Тип | Применение |
|-----|------------|
| **Функциональное** | Проверка работы каждой функции |
| **Регрессионное** | Повторная проверка после изменений |
| **UI/UX** | Проверка внешнего вида и удобства |
| **Кроссбраузерное** | Проверка в Chrome, Firefox |
| **Граничные значения** | Проверка полей на границах допустимых значений |
| **Тестирование API** | Проверка запросов через DevTools |
| **Адаптивное** | Проверка на мобильных/планшетах |

### Подход к тестированию

1. **Тест-дизайн** — составление чек-листов и тест-кейсов на основе требований и здравого смысла.
2. **Выполнение тестов** — последовательное прохождение всех проверок.
3. **Баг-репортинг** — оформление найденных дефектов в Jira.
4. **Регрессия** — повторная проверка после исправлений.
5. **Отчётность** — итоговый отчёт о тестировании.

## 8. Критерии начала и завершения

### Критерии начала тестирования

- Сайт доступен по адресу https://www.saucedemo.com/.
- Все тестовые пользователи работают.
- Тест-план утверждён.
- Чек-листы и тест-кейсы готовы.

### Критерии завершения тестирования

- Все запланированные чек-листы выполнены.
- Все найденные баги задокументированы в Jira.
- Итоговый отчёт о тестировании составлен.
- Проведено регрессионное тестирование после исправлений.

### Критерии приостановки тестирования

- Сайт недоступен более 1 часа.
- Критический баг блокирует дальнейшее тестирование.
- Изменения в требованиях во время тестирования.
