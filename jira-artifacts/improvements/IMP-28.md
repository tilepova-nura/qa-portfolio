# IMP-28: Исправить изображения для problem_user

**Текущее состояние:**
Для пользователя problem_user вместо изображений товаров отображаются изображения собачек.

**Предлагаемое улучшение:**
Настроить корректную загрузку изображений товаров для всех пользователей, включая problem_user.

**Обоснование:**
- Пользователь должен видеть корректные изображения товаров.
- Текущее отображение собачек вместо товаров вводит в заблуждение.
- Улучшает пользовательский опыт.
