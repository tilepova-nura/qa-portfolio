# IMP-09: Сделать логотип "Swag Labs" кликабельным

**Текущее состояние:**
Логотип "Swag Labs" в левом верхнем углу неактивен — при нажатии на него ничего не происходит.

**Предлагаемое улучшение:**
Сделать логотип кликабельным. При нажатии на него должен происходить переход на главную страницу (inventory.html).

**Обоснование:**
Это стандартная практика для всех веб-сайтов — логотип всегда ведёт на главную. Улучшает навигацию и пользовательский опыт.
