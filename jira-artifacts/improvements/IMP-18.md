# IMP-18: Добавить проверку на допустимые символы для First Name и Last Name

**Текущее состояние:**
Поля First Name и Last Name принимают спецсимволы и цифры как валидный ввод.

**Предлагаемое улучшение:**
Ограничить допустимые символы только буквами (латиница и/или кириллица) и добавить сообщение при нарушении: "First Name must contain only letters".

**Обоснование:**
- Стандартная практика для полей имени и фамилии.
- Предотвращает ввод недопустимых символов.
- Улучшает UX — пользователь знает допустимые символы.

**Связанные проверки:** [Чек-лист №9](../checklists/checklist-09-checkout-step1.md) (проверки 2.1.6, 2.1.7, 2.2.6, 2.2.7, 3.7)
