# IMP-12: Добавить чек-боксы для выбора товаров в корзине

**Текущее состояние:**
В корзине нет возможности выбрать только часть товаров для покупки — все товары покупаются вместе.

**Предлагаемое улучшение:**
Добавить чек-боксы рядом с каждым товаром в корзине, чтобы пользователь мог выбрать только нужные товары для оформления заказа.

**Обоснование:**
- Даёт пользователю гибкость в управлении заказом.
- Соответствует стандартам интернет-магазинов.
- Улучшает пользовательский опыт.

**Связанные проверки:** Чек-лист №6 (проверка 2.7)
