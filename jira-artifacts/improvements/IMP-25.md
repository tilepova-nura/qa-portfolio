# IMP-25: Исправить вывод данных пользователя в PDF-заказе

**Текущее состояние:**
Вместо имени пользователя и адреса отображаются нечитаемые символы.

**Предлагаемое улучшение:**
Настроить корректную передачу данных из формы оформления заказа в PDF-документ. Вместо технических символов должны отображаться введённые пользователем First Name, Last Name и Zip/Postal Code.

**Обоснование:**
- Это критически важная информация для доставки.
- Текущее отображение делает документ бесполезным.

**Связанные проверки:** Чек-лист №11 (проверка 3.6)
**Связанные баги:** BUG-18
