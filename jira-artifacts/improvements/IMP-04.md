# IMP-04: Добавить ограничение на максимальную длину для поля "Password"

**Текущее состояние:**
Поле "Password" принимает 1000+ символов без ограничения.

**Предлагаемое улучшение:**
Установить ограничение (например, 30–50 символов) и добавить сообщение при превышении.

**Обоснование:**
- Соответствует лучшим практикам безопасности.
- Улучшает UX — пользователь знает лимит.
- Предотвращает возможные проблемы с производительностью.
