# IMP-05: Добавить проверку на допустимые символы для поля "Username"

**Текущее состояние:**
Поле "Username" принимает любые символы, включая спецсимволы, кириллицу и иероглифы.

**Предлагаемое улучшение:**
Ограничить допустимые символы (только латинские буквы и цифры). Добавить подсказку: "Логин должен содержать только латинские буквы и цифры".

**Обоснование:**
- Стандартная практика для полей логина.
- Предотвращает возможные проблемы с безопасностью.
- Улучшает UX — пользователь знает допустимые символы.

**Связанные тест-кейсы:** [TC-21](../test-cases/TC-21.md)
