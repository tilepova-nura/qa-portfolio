# IMP-23: Добавить изображения товаров на странице Overview

**Текущее состояние:**
На странице Checkout: Overview не отображаются изображения товаров.

**Предлагаемое улучшение:**
Добавить миниатюры (превью) товаров рядом с их описанием, чтобы пользователь мог визуально идентифицировать товар.

**Обоснование:**
- Визуальная идентификация товара важна для пользователя.
- Соответствует стандартам интернет-магазинов.
- Улучшает пользовательский опыт.
