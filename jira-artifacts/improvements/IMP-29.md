# IMP-29: Добавить визуальные индикаторы загрузки для всех пользователей

**Текущее состояние:**
При выполнении любых действий на сайте (переход на страницу товара, выбор фильтра, переход по меню, возврат на главную) пользователь не видит никаких визуальных индикаторов загрузки. Это особенно критично для пользователя performance_glitch_user, у которого все действия выполняются с задержкой до 10-15 секунд.

**Предлагаемое улучшение:**
1. Добавить визуальные индикаторы загрузки (спиннеры, прогресс-бары) при выполнении любых действий на сайте.
2. Отображать индикатор загрузки при:
   - Переходе на страницу товара
   - Возврате на главную страницу
   - Выборе фильтра сортировки
   - Переходе по пунктам меню (About, All Items и т.д.)
   - Добавлении/удалении товаров из корзины
   - Оформлении заказа

**Обоснование:**
- Пользователь должен понимать, что система выполняет действие, а не зависла.
- Критически важно для пользователей с медленным соединением (performance_glitch_user).
- Улучшает пользовательский опыт (UX).
- Соответствует современным стандартам веб-приложений.
