# IMP-19: Добавить проверку на минимальную длину для Zip/Postal Code

**Текущее состояние:**
Поле Zip/Postal Code принимает 1 символ как валидный ввод без предупреждения.

**Предлагаемое улучшение:**
Установить минимальную длину (например, 3–5 символов) и добавить сообщение при нарушении: "Zip/Postal Code must be at least 3 characters".

**Обоснование:**
- Почтовый индекс должен иметь определённую длину.
- Предотвращает ввод слишком коротких индексов.
- Соответствует стандартам.

**Связанные проверки:** [Чек-лист №9](../checklists/checklist-09-checkout-step1.md) (проверка 2.3.3)
