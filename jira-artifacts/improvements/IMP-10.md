# IMP-10: Закрытие бокового меню по клику вне него

**Текущее состояние:**
Боковое меню (бургер-меню) закрывается только при нажатии на крестик (X). При клике на любую область вне меню — меню остаётся открытым.

**Предлагаемое улучшение:**
Добавить закрытие меню при клике вне его области (на пустое место страницы).

**Обоснование:**
- Соответствует стандартному поведению модальных окон и меню.
- Улучшает пользовательский опыт — не нужно искать крестик.
- Уменьшает количество лишних кликов.
