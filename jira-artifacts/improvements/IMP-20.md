# IMP-20: Добавить проверку формата для Zip/Postal Code (только цифры)

**Текущее состояние:**
Поле Zip/Postal Code принимает буквы, спецсимволы и кириллицу как валидный ввод.

**Предлагаемое улучшение:**
Ограничить допустимые символы только цифрами (0-9) и добавить сообщение при нарушении: "Zip/Postal Code must contain only digits".

**Обоснование:**
- Почтовый индекс должен содержать только цифры.
- Предотвращает ввод некорректных данных.
- Соответствует стандартам.

**Связанные проверки:** [Чек-лист №9](../checklists/checklist-09-checkout-step1.md) (проверки 2.3.6, 2.3.7, 2.3.8, 3.8)
