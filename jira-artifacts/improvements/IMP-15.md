# IMP-15: Добавить обрезку пробелов (trim) для всех полей

**Текущее состояние:**
Поля First Name, Last Name, Zip/Postal Code принимают пробелы как валидный ввод. Пробелы в начале и конце не обрезаются.

**Предлагаемое улучшение:**
Автоматически обрезать пробелы (trim) при вводе или отправке формы для всех полей.

**Обоснование:**
- Улучшает пользовательский опыт — пользователь не думает о пробелах.
- Соответствует лучшим практикам веб-форм.
- Предотвращает ошибки, связанные с лишними пробелами.

**Связанные проверки:** Чек-лист №9 (проверки 2.1.2, 2.2.2, 2.3.2, 3.6)
