# IMP-14: Добавить выбор количества товара в корзине

**Текущее состояние:**
В корзине можно добавить только 1 единицу товара. Нет возможности увеличить или уменьшить количество.

**Предлагаемое улучшение:**
Добавить поле или кнопки (+, -) для изменения количества товара в корзине.

**Обоснование:**
- Пользователи часто хотят купить несколько единиц одного товара.
- Соответствует стандартам интернет-магазинов.
- Улучшает пользовательский опыт.
