# IMP-24: Улучшить дизайн и информативность PDF-заказа

**Текущее состояние:**
PDF-документ содержит минимум информации, не имеет структуры и сложен для восприятия.

**Предлагаемое улучшение:**
Переработать дизайн PDF-документа:
- Добавить номер заказа и дату оформления.
- Добавить информацию о пользователе (имя, адрес).
- Добавить таблицу с товарами: название, количество, цена за единицу, итоговая цена.
- Улучшить читаемость шрифта и структуры.
- Добавить итоговую информацию: сумма товаров, налог, общая стоимость.

**Обоснование:**
- Это официальный документ для пользователя.
- Должен содержать всю необходимую информацию о заказе.
- Улучшает пользовательский опыт и доверие к сервису.

**Связанные проверки:** Чек-лист №11 (проверки 3.3, 3.4, 3.5)
**Связанные баги:** BUG-17
