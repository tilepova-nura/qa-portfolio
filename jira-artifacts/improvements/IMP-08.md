# IMP-08: Добавить проверку на минимальную длину для поля "Password"

**Текущее состояние:**
Поле "Password" принимает пароли из 1-2 символов без предупреждения.

**Предлагаемое улучшение:**
Установить минимальную длину (например, 6–8 символов) и добавить сообщение при нарушении.

**Обоснование:**
- Соответствует лучшим практикам безопасности (OWASP рекомендует минимум 8 символов).
- Предотвращает использование слишком простых паролей.
- Улучшает UX — пользователь понимает, почему его пароль не принимается.

**Связанные проверки:** [Чек-лист №1](../checklists/checklist-01-validation.md) (проверка 2.9)
