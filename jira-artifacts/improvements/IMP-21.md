# IMP-21: Добавить анимацию для всех кнопок

**Текущее состояние:**
У всех кнопок на сайте нет анимации. Они всегда одного цвета, нет визуальной обратной связи при наведении, нажатии или в неактивном состоянии.

**Предлагаемое улучшение:**
1. Добавить эффект при наведении (hover) — изменение цвета, тень.
2. Добавить эффект при нажатии (active) — уменьшение, затемнение.
3. Добавить визуальное отличие для неактивных кнопок (disabled) — затемнение, изменение прозрачности.

**Обоснование:**
- Улучшает пользовательский опыт (UX).
- Даёт пользователю обратную связь о действиях.
- Соответствует современным стандартам веб-дизайна.

**Связанные проверки:** Чек-лист №10 (проверки 4.1, 4.2, 4.3)
