# IMP-06: Добавить проверку на допустимые символы для поля "Password"

**Текущее состояние:**
Поле "Password" принимает любые символы, включая спецсимволы, кириллицу и иероглифы.

**Предлагаемое улучшение:**
Добавить проверку (только латинские буквы, цифры и ограниченный набор спецсимволов). Добавить подсказку: "Пароль должен содержать только латинские буквы и цифры".

**Обоснование:**
- Соответствует политикам безопасности.
- Улучшает UX — пользователь знает допустимые символы.

**Связанные проверки:** Чек-лист №1 (проверки 2.11, 2.12, 2.13, 3.6)
