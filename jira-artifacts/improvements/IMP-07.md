# IMP-07: Добавить проверку на минимальную длину для поля "Username"

**Текущее состояние:**
Поле "Username" принимает логины из 1-2 символов без предупреждения.

**Предлагаемое улучшение:**
Установить минимальную длину (например, 3–6 символов) и добавить сообщение при нарушении.

**Обоснование:**
- Соответствует лучшим практикам веб-форм.
- Предотвращает создание слишком простых логинов.
- Улучшает UX — пользователь понимает, почему его логин не принимается.

**Связанные проверки:** [Чек-лист №1](../checklists/checklist-01-validation.md) (проверки 1.10, 1.11)
