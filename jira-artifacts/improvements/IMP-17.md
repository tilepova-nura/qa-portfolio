# IMP-17: Добавить проверку на минимальную длину для First Name и Last Name

**Текущее состояние:**
Поля First Name и Last Name принимают 1 символ как валидный ввод без предупреждения.

**Предлагаемое улучшение:**
Установить минимальную длину (например, 2 символа) и добавить сообщение при нарушении: "First Name must be at least 2 characters".

**Обоснование:**
- Соответствует лучшим практикам веб-форм.
- Предотвращает ввод слишком коротких имён.
- Улучшает UX — пользователь понимает, почему его имя не принимается.

**Связанные проверки:** [Чек-лист №9](../checklists/checklist-09-checkout-step1.md) (проверки 2.1.3, 2.2.3)
