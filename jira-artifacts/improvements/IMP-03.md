# IMP-03: Добавить ограничение на максимальную длину для поля "Username"

**Текущее состояние:**
Поле "Username" принимает 1000+ символов без ограничения.

**Предлагаемое улучшение:**
Установить ограничение (например, 20–30 символов) и добавить сообщение при превышении.

**Обоснование:**
- Предотвращает возможные проблемы с производительностью.
- Улучшает UX — пользователь знает лимит.
- Соответствует стандартам веб-форм.

**Связанные проверки:** [Чек-лист №1](../checklists/checklist-01-validation.md) (проверка 1.12)
