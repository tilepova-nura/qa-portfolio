# IMP-11: Добавить изображения товаров в корзине

**Текущее состояние:**
На странице корзины отображается только название, цена и описание товара. Изображения товаров отсутствуют.

**Предлагаемое улучшение:**
Добавить миниатюры (превью) товаров в корзине, чтобы пользователь мог визуально идентифицировать товар.

**Обоснование:**
- Визуальная идентификация товара важна для пользователя.
- Улучшает пользовательский опыт.
- Соответствует стандартам интернет-магазинов.
