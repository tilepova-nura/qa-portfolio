# IMP-16: Добавить ограничение на максимальную длину для всех полей

**Текущее состояние:**
Поля First Name, Last Name, Zip/Postal Code принимают 1000+ символов без ограничения.

**Предлагаемое улучшение:**
Установить ограничение на максимальную длину (например, 50 символов для имени, 50 для фамилии, 10 для почтового индекса) и добавить сообщение при превышении.

**Обоснование:**
- Предотвращает возможные проблемы с производительностью.
- Улучшает UX — пользователь знает лимит.
- Соответствует стандартам веб-форм.

**Связанные проверки:** Чек-лист №9 (проверки 2.1.5, 2.2.5, 2.3.5)
