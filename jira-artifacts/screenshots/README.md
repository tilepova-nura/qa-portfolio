# Скриншоты и видео

В этой папке собраны медиафайлы, приложенные к баг-репортам.

Файлы названы по формату:
- `BUG-XX_screenshot.png` — скриншот бага
- `BUG-XX_video.mp4` — видео с воспроизведением бага

**Содержание:**
- Скриншоты визуальных нарушений (съехавшие элементы, неправильные отступы, изображения собачек)
- Скриншоты ошибок в интерфейсе (всплывающие окна, сообщения)
- Видео с демонстрацией задержек (performance_glitch_user)
- Видео с демонстрацией неработающих кнопок
- Скриншоты проблем с PDF-заказами (нечитаемые данные, задвоение суммы)

Все медиафайлы привязаны к соответствующим багам в Jira и используются для наглядного подтверждения дефектов.
