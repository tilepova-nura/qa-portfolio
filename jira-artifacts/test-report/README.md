## 6. Ключевые проблемы

### 🔴 Критические проблемы

1. **Кнопка "Finish" не работает для error_user** — заказ невозможно завершить, PDF недоступен.
2. **Нельзя добавить больше 2 товаров в корзину для problem_user.**
3. **Ошибка при сортировке для error_user** (всплывающее окно "Sorting is broken!").
4. **PDF-заказ не содержит важной информации** (номер заказа, данные доставки, имя пользователя).
5. **Прямой доступ к Checkout: Overview без заполнения данных** для problem_user и error_user.

### 🟠 Основные проблемы

1. **Пробелы в начале и конце полей ввода** не обрезаются (Username, Password).
2. **Отсутствует валидация длины и допустимых символов** в полях ввода.
3. **Некорректная навигация** — кнопки "Cancel" и "Back" ведут не туда, куда должны.
4. **Медленная загрузка для performance_glitch_user** (более 10–15 секунд без индикаторов).
5. **Визуальные баги для visual_user** — съехавшие элементы, разный размер изображений.

## 8. Выводы

- Для **standard_user** сайт работает стабильно, критических проблем нет.
- Для **problem_user, error_user, performance_glitch_user, visual_user** выявлено множество критических и серьёзных багов, которые делают работу с сайтом невозможной или сильно затруднённой.
- **Валидация полей** требует серьёзной доработки (пробелы, длина, символы, формат).
- **PDF-заказ** требует полной переработки — документ бесполезен в текущем виде.
- **Навигация** между страницами работает некорректно в нескольких местах.
- **Производительность** для отдельных пользователей требует оптимизации.

## 9. Рекомендации

1. **Исправить все критические баги (Critical)** перед релизом.
2. **Добавить валидацию на стороне клиента** для всех полей ввода.
3. **Переработать генерацию PDF-документа** — добавить всю необходимую информацию.
4. **Исправить навигацию** — кнопки Cancel и Back должны вести на правильные страницы.
5. **Оптимизировать производительность** для performance_glitch_user.
6. **Реализовать предложенные улучшения** из папки [`improvements/`](../improvements/).
7. **Провести повторное тестирование** после исправления багов (регресс).
