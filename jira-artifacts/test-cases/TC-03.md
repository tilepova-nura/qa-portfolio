# TC-03: Проверка входа с проблемным пользователем (problem_user)

**Приоритет:** Medium

**Предусловия:** 
- Открыта страница https://www.saucedemo.com/
- Поля ввода пустые

**Тестовые данные:**

| Поле | Значение |
|------|----------|
| Username | `problem_user` |
| Password | `secret_sauce` |

**Шаги воспроизведения:**
1. В поле "Username" ввести `problem_user`
2. В поле "Password" ввести `secret_sauce`
3. Нажать кнопку "Login"

**Ожидаемый результат:**
- Пользователь авторизован (редирект на страницу товаров)
- На странице товаров могут наблюдаться визуальные баги:
  - Некоторые изображения товаров отсутствуют или отображаются некорректно
  - Иконки или кнопки могут работать не так, как ожидается
  - Основная функциональность (добавление в корзину) может работать с ошибками

**Постусловия:**
- Выйти из системы (Logout)

**Связанные проверки:** Чек-лист №2 (проверка 1.2)
**Связанные баги:** BUG-02, BUG-23, BUG-24, BUG-25, BUG-26, BUG-27
