# TC-07: Проверка входа с performance_glitch_user

**Приоритет:** Medium

**Предусловия:**
- Открыта страница https://www.saucedemo.com/
- Поля ввода пустые

**Тестовые данные:**

| Поле | Значение |
|------|----------|
| Username | `performance_glitch_user` |
| Password | `secret_sauce` |

**Шаги воспроизведения:**
1. В поле "Username" ввести `performance_glitch_user`
2. В поле "Password" ввести `secret_sauce`
3. Нажать кнопку "Login"

**Ожидаемый результат:**
- Пользователь успешно авторизован (редирект на страницу товаров)
- Время загрузки страницы может быть заметно дольше, чем у обычного пользователя (задержка ~5–10 секунд)
- Это особенность этого пользователя — он симулирует медленное соединение
- Если задержка превышает 10 секунд — это можно оформить как баг

**Постусловия:**
- Выйти из системы (Logout)
