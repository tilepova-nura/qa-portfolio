# TC-21: Проверка валидации полей ввода (граничные значения)

**Приоритет:** High

**Предусловия:** 
- Открыта страница https://www.saucedemo.com/
- Поля ввода пустые

**Тестовые данные:**

| Поле | Значение | Ожидаемый результат |
|------|----------|---------------------|
| Username | (пусто) | "Username is required" |
| Username | "   " (пробелы) | "Username is required" |
| Username | 1000 символов | Ограничение длины + ошибка |
| Username | `user!@#$%^&*()` | Ошибка "Логин должен содержать только латинские буквы и цифры" |
| Username | `' OR '1'='1` | Безопасная обработка |
| Password | (пусто) | "Password is required" |
| Password | 1000 символов | Ограничение длины + ошибка |
| Password | `pass!@#$%^&*()` | Ошибка "Пароль должен содержать только латинские буквы и цифры" |

**Шаги воспроизведения:**
1. Для каждого набора данных выполнить:
   - Ввести значение в поле
   - Нажать "Login"
   - Проверить результат

**Ожидаемый результат:**
- Система корректно обрабатывает все граничные значения
- Сообщения об ошибках отображаются для невалидных данных

**Постусловия:**
- Закрыть все сообщения об ошибках

**Связанные проверки:** Чек-лист №1 (все проверки)
**Связанные баги:** BUG-06, BUG-07, BUG-08, BUG-09, IMP-03, IMP-04, IMP-05, IMP-06, IMP-07, IMP-08
