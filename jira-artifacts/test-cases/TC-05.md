# TC-05: Проверка входа с пустым полем Password

**Приоритет:** High

**Предусловия:** 
- Открыта страница https://www.saucedemo.com/
- Поля ввода пустые

**Тестовые данные:**

| Поле | Значение |
|------|----------|
| Username | `standard_user` |
| Password | (оставить пустым) |

**Шаги воспроизведения:**
1. В поле "Username" ввести `standard_user`
2. Оставить поле "Password" пустым
3. Нажать кнопку "Login"

**Ожидаемый результат:**
- Авторизация не выполняется
- Появляется сообщение об ошибке: "Epic sadface: Password is required"
- Поле ввода username не очищается
- Пользователь остаётся на странице логина

**Постусловия:**
- Закрыть сообщение об ошибке

**Связанные проверки:** Чек-лист №2 (проверка 2.3)
**Связанные баги:** — (не найдены)
