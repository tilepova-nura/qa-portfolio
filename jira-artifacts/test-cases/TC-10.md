# TC-10: Проверка отображения всех товаров на главной странице

**Приоритет:** Medium

**Предусловия:** 
- Пользователь авторизован под стандартным пользователем (`standard_user` / `secret_sauce`)

**Тестовые данные:**

| Поле | Значение |
|------|----------|
| Username | `standard_user` |
| Password | `secret_sauce` |

**Шаги воспроизведения:**
1. Открыть главную страницу https://www.saucedemo.com/inventory.html
2. Проверить, что отображается список товаров
3. Проверить, что у каждого товара есть название, цена, описание и кнопка "Add to cart" (или "Remove")

**Ожидаемый результат:**
- На странице отображаются все товары (Sauce Labs Backpack, Bike Light, Bolt T-Shirt, Fleece Jacket, Onesie, Test.allTheThings() T-Shirt (Red))
- Каждый товар имеет название, цену, описание, изображение и интерактивную кнопку

**Постусловия:**
- Выйти из системы (Logout)

**Связанные проверки:** Чек-лист №3 (проверка 2.1)
**Связанные баги:** — (не найдены)
