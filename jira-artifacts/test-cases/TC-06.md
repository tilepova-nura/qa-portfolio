# TC-06: Проверка входа с неверным паролем

**Приоритет:** High

**Предусловия:**
- Открыта страница https://www.saucedemo.com/
- Поля ввода пустые

**Тестовые данные:**

| Поле | Значение |
|------|----------|
| Username | `standard_user` |
| Password | `wrong_password` |

**Шаги воспроизведения:**
1. В поле "Username" ввести `standard_user`
2. В поле "Password" ввести `wrong_password` (или любой другой неверный пароль, не равный `secret_sauce`)
3. Нажать кнопку "Login"

**Ожидаемый результат:**
- Авторизация не выполняется
- Появляется сообщение об ошибке: "Epic sadface: Username and password do not match"
- Поля ввода не очищаются (сохраняют введённые значения)
- Пользователь остаётся на странице логина

**Постусловия:**
- Закрыть сообщение об ошибке

**Связанные баги:** — (не найдены)
