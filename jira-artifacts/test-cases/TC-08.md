# TC-08: Проверка входа с error_user

**Приоритет:** Medium

**Предусловия:** 
- Открыта страница https://www.saucedemo.com/
- Поля ввода пустые

**Тестовые данные:**

| Поле | Значение |
|------|----------|
| Username | `error_user` |
| Password | `secret_sauce` |

**Шаги воспроизведения:**
1. В поле "Username" ввести `error_user`
2. В поле "Password" ввести `secret_sauce`
3. Нажать кнопку "Login"

**Ожидаемый результат:**
- Пользователь авторизован (редирект на страницу товаров)
- На странице могут наблюдаться ошибки:
  - Некоторые кнопки (например, "Add to cart") могут не работать
  - Иконки или изображения могут отсутствовать
  - Возможны ошибки в консоли браузера
- Это особенность этого пользователя — он симулирует ошибки на клиентской стороне

**Постусловия:**
- Выйти из системы (Logout)

**Связанные проверки:** Чек-лист №2 (проверка 1.4)
**Связанные баги:** BUG-03, BUG-33, BUG-34, BUG-35, BUG-36, BUG-37, BUG-38, BUG-45
