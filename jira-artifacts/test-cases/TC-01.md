# TC-01: Проверка входа с валидными данными

**Приоритет:** High

**Предусловия:** 
- Открыта страница https://www.saucedemo.com/
- Поля ввода пустые

**Тестовые данные:**

| Поле | Значение |
|------|----------|
| Username | `standard_user` |
| Password | `secret_sauce` |

**Шаги воспроизведения:**
1. В поле "Username" ввести `standard_user`
2. В поле "Password" ввести `secret_sauce`
3. Нажать кнопку "Login"

**Ожидаемый результат:**
- Пользователь успешно авторизован
- Происходит редирект на главную страницу каталога товаров (https://www.saucedemo.com/inventory.html)
- В верхней части экрана отображается название "Swag Labs" и иконка корзины
- Отображается список товаров (Sauce Labs Backpack, Bike Light и т.д.)

**Постусловия:**
- Выйти из системы (Logout)

**Связанные проверки:** Чек-лист №2 (проверка 1.1)
**Связанные баги:** — (не найдены)
