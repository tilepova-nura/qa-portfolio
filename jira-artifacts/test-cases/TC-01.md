# TC-02: Проверка входа с заблокированным пользователем (locked_out_user)

**Приоритет:** High

**Предусловия:** 
- Открыта страница https://www.saucedemo.com/
- Поля ввода пустые

**Тестовые данные:**

| Поле | Значение |
|------|----------|
| Username | `locked_out_user` |
| Password | `secret_sauce` |

**Шаги воспроизведения:**
1. В поле "Username" ввести `locked_out_user`
2. В поле "Password" ввести `secret_sauce`
3. Нажать кнопку "Login"

**Ожидаемый результат:**
- Авторизация не выполняется
- Появляется сообщение об ошибке: "Epic sadface: Sorry, this user has been locked out."
- Пользователь остаётся на странице логина
- Поля ввода не очищаются (сохраняют введённые значения)

**Постусловия:**
- Закрыть сообщение об ошибке

**Связанные проверки:** Чек-лист №2 (проверка 2.1)
**Связанные баги:** BUG-05
