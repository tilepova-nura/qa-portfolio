# Тест-кейсы

В этой папке собраны все тест-кейсы, созданные для тестирования **SauceDemo (Swag Labs)**.

Тест-кейсы покрывают:
- Авторизацию (валидные и невалидные данные, различные типы пользователей)
- Главную страницу (отображение товаров, добавление/удаление в корзину)
- Фильтрацию товаров (сортировка по имени и цене)
- Страницу товара
- Боковое меню (бургер)
- Мобильную адаптивность
- Оформление заказа (Шаги 1, 2 и завершение)
- Валидацию полей ввода (граничные значения)

Каждый тест-кейс содержит:
- Приоритет
- Предусловия
- Тестовые данные
- Шаги воспроизведения
- Ожидаемый результат
- Постусловия
- Ссылки на связанные чек-листы и баги

**Всего тест-кейсов:** 21
