# TC-04: Проверка входа с пустым полем Username

**Приоритет:** High

**Предусловия:**
- Открыта страница https://www.saucedemo.com/
- Поля ввода пустые

**Тестовые данные:**

| Поле | Значение |
|------|----------|
| Username | (оставить пустым) |
| Password | `secret_sauce` |

**Шаги воспроизведения:**
1. Оставить поле "Username" пустым
2. В поле "Password" ввести `secret_sauce`
3. Нажать кнопку "Login"

**Ожидаемый результат:**
- Авторизация не выполняется
- Появляется сообщение об ошибке: "Epic sadface: Username is required"
- Поле ввода пароля не очищается
- Пользователь остаётся на странице логина

**Постусловия:**
- Закрыть сообщение об ошибке
