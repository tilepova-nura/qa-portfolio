# TC-09: Проверка входа с visual_user

**Приоритет:** Medium

**Предусловия:**
- Открыта страница https://www.saucedemo.com/
- Поля ввода пустые

**Тестовые данные:**

| Поле | Значение |
|------|----------|
| Username | `visual_user` |
| Password | `secret_sauce` |

**Шаги воспроизведения:**
1. В поле "Username" ввести `visual_user`
2. В поле "Password" ввести `secret_sauce`
3. Нажать кнопку "Login"

**Ожидаемый результат:**
- Пользователь авторизован (редирект на страницу товаров)
- Могут наблюдаться визуальные баги:
  - Неправильные отступы или выравнивание элементов
  - Некорректные цвета или шрифты
  - Элементы интерфейса накладываются друг на друга
- Это особенность этого пользователя — он симулирует проблемы с CSS/вёрсткой

**Постусловия:**
- Выйти из системы (Logout)
