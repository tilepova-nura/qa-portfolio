# Анализ сетевого трафика (Wireshark)

В этой папке собраны задания по анализу сетевого трафика с помощью снифера **Wireshark**. 
Каждое задание показывает отдельный навык: от базового захвата пакетов до расшифровки HTTPS.

---

## 📂 Структура папки

| Папка | Что внутри | Навык |
|-------|------------|-------|
| [wireshark-saucedemo](./wireshark-saucedemo/) | Захват и анализ TLS-трафика SauceDemo | Базовый захват, фильтрация, анализ протоколов, TLS-рукопожатие |
| [wireshark-http](./wireshark-http/) | Анализ незашифрованного HTTP-трафика (vulnweb) | Понимание разницы HTTP vs HTTPS, поиск данных в открытом виде |
| [wireshark-dns](./wireshark-dns/) | Анализ DNS-запросов | Понимание работы DNS, отслеживание доменов |
| [wireshark-https](./wireshark-https/) | Расшифровка HTTPS через SSLKEYLOGFILE (GET) | Расшифровка HTTPS-трафика |
| [wireshark-https-post](./wireshark-https-post/) | Расшифровка HTTPS POST-запроса (httpbin.org) | Расшифровка POST-запросов с реальными данными |

---

## 🎯 Что я умею на примере этих заданий

- ✅ Захватывать сетевой трафик с помощью Wireshark
- ✅ Фильтровать пакеты по IP-адресу, протоколу, домену
- ✅ Анализировать структуру протоколов (TCP, TLS, HTTP/2, DNS, QUIC)
- ✅ Определять IP-адреса сайтов через `nslookup`
- ✅ Понимать TLS-рукопожатие и находить SNI
- ✅ Расшифровывать HTTPS-трафик через SSLKEYLOGFILE
- ✅ Видеть содержимое POST-запросов и данные форм
- ✅ Понимать, чем HTTP отличается от HTTPS
- ✅ Находить уязвимости (передача паролей в открытом виде)

## 🛠️ Инструменты

- **Wireshark 4.6.8**
- **Google Chrome v120+**
- **Windows 11**
- **SSLKEYLOGFILE** (для расшифровки HTTPS)
- **nslookup** (для определения IP-адресов)
